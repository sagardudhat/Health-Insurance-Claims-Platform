# Health Insurance Claims Processing Platform

A full-stack, multi-role Health Insurance Claims Processing Platform with state-machine workflow enforcement, coverage calculation rules, audit trail tracking, and rule-based fraud detection.

## Tech Stack
- **Backend**: Node.js, Express, TypeScript, Mongoose (MongoDB), JWT, Zod, Multer
- **Frontend**: Next.js 14 App Router, TypeScript, Tailwind CSS, shadcn/ui, TanStack Query & Table, Zustand, Recharts
